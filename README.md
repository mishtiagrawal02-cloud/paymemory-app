# 🚀 PayMemory — Financial Memory Layer for UPI

> Turn your UPI transaction history into a **searchable, contextual financial memory**.

Apps like Google Pay and PhonePe show you what you paid.  
**PayMemory helps you remember why you paid, what it meant, and what to do next.**

---

## ✨ Features

- 📱 **Rich Transaction Feed**  
  Convert basic transactions into meaningful records with context.

- 📎 **Receipt & Document Attachments**  
  Attach bills, warranty cards, and invoices to any transaction.

- 🏷️ **Smart Tagging (AI-assisted)**  
  Automatically categorize transactions (rent, food, loan, etc.)

- ⏰ **Reminders & Alerts**  
  Never miss repayments, subscriptions, or warranty expiries.

- 🔍 **Semantic Search**  
  Search like:
  - "money I gave Amit"
  - "clothes bought in March"

- 👥 **Relationship Layer**  
  Tag contacts as *friend, landlord, client* and track interactions.

---

## 🧠 Problem

UPI apps show:
> "Paid Ramesh ₹4500"

But they don’t answer:
- Why did I pay?
- Is this a loan or expense?
- Will I get this money back?
- Do I need to follow up?

---

## ✅ Solution

PayMemory turns raw transactions into **structured financial stories** with context, reminders, and search.

---

## 🛠️ Tech Stack

- React (Vite)
- Firebase (Auth, Firestore, Storage)
- OpenAI API (for tagging & search)
- OCR (Tesseract / Google Vision)
